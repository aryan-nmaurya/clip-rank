# Movie / Trailer Moments

Movie is the fourth existing-app creation mode (`movie`), not a separate application. The local API accepts one authorized URL or upload; simple creation automatically chooses dialogue, commentary or a cinematic presentation. Advanced defaults are collapsed. Source permission applies to video and audio. The channel's documented-permission policy additionally requires evidence; user declarations are recorded as declarations, not independently verified rights or copyright clearance.

The movie pipeline reuses the shared SQLite project/jobs/clips, bounded JobEngine, ingestion, cached faster-whisper, AI provider router, Pocket TTS, Pillow captions, FFmpeg reframer, objective encoded-MP4 QC, Library, gated media/download routes and native YouTube upload/copyright review. Movies stay on the local worker/server; Vercel receives no rendering work. The existing entertainment Autopilot identity is unchanged.

Full-source cheap preprocessing bounds samples at 1,800 160×90 frames and reads low-rate audio energy. Shot boundaries, motion, contrast and protected speech clusters produce windows distributed over the whole movie. Quiet dialogue exchanges have reserved slots so action does not crowd them out. At most 20 windows receive frame analysis. When the connected provider supports video, up to ten distinct finalists then receive short source-video/audio reviews before production; the entire movie is never sent to the model. Auto tries connected local vision first, with Gemini escalation only for uncertain/invalid local results. Local-only never escalates to cloud. No local AI model downloads are triggered.

MovieMomentScorer performs weighted arithmetic on individually validated dimensions. MovieFormatDirector first protects meaningful dialogue, then selects value-adding commentary, then strong cinematography with authorized audio; otherwise it rejects the moment. Temporal overlap plus representative-frame/description similarity suppress repeated moments. Original licensed movie sound can carry a cinematic edit; additional tracks come only from the documented, content-hash-bound local music library and must match the scene mood.

Commentary uses complete, conversational sentences across the whole Short: an immediate hook, continuing story context and a conclusion grounded in the visible payoff. The director inspects separate time-aligned source excerpts, writes a duration-based script, and rewrites only a failed beat when measured natural-speed speech does not fit; audio is never sped up to fill the timeline. Short speech beats avoid the alignment model's thirty-second forced-alignment limit. Natural breaths between beats are retained, final narration must reach the last two seconds, and measured original speech remains protected. Editing notes about camera transitions or visual scale are rejected as narration. Dialogue/cinematic clips never invoke TTS. Selected excerpts are transcribed again without VAD suppressing quiet actor lines. Speech captions use measured words; simultaneous original/narration captions are prevented. Movie mode defaults to a mobile-filling 9:16 crop: original-frame vision locates the story subject and local analysis measures the source geometry. Advanced offers preserved wide composition when desired. Final QC rejects crops that lose the important action. Large, mobile-readable movie headers display for at most 2.5 seconds. Copyright/attribution text is never burned over the footage; required credits are retained in publish descriptions and downloaded metadata.

Every render goes through H.264/AAC/48-kHz/1080×1920 decode validation, frame/audio inspection, format-specific caption/dialogue/audio checks and actual-final-video (or sampled-frame + objective-audio) review. Each clip has at most three repair attempts. Only passed final clips enter Library/download/publishing. Internal scores are editorial estimates, never viral probabilities.

A source-content hash binds saved transcription and moment analysis to the actual source, so a URL retry with unchanged bytes can reuse analysis. Final review first observes the actual video without the proposed plot, then compares its evidence with the title/scene claims, reducing confirmation of invented story details. Schema correction has bounded retries and does not relax quality checks. Final render retries reuse the analysis and source. Completed or unrecoverably failed/cancelled movie jobs delete only their managed temporary workspace, including the ingress upload copy; user files outside it are untouched. URL retries may redownload the source after terminal cleanup. Uploaded sources that have been cleaned require another upload. The worker bounds temporary movie storage to 4 GB and uses the shared media timeout/cancellation mechanism.

Current movie speech support is English. Other languages fail clearly rather than using an English Pocket TTS voice or inaccurate captions. Source separation and speed ramps are optional and are not run automatically; source ducking and original cinematic rhythm are preferred where sufficient. Copyright clearance remains the existing separate private-upload → real Studio review → public-release flow; source license metadata never substitutes for an actual YouTube verdict.

## Acceptance coverage

Movie format fixtures render actual moving-footage MP4s with real FFmpeg audio, test no TTS in dialogue/cinematic branches, protected narration scheduling, clean temporary storage, downloadable QC records, permission policies, strict model fields, bounded full-source sampling, music license/mood/hash checks, and local-origin restrictions. The full Sintel test uses the user-authorized official Blender source and retains attribution/license references.
